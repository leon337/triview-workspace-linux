# LEA-196 — Workspaces persistentes e restauração de estado

Status: implementação concluída; aguardando validação visual no Linux Mint.

## Objetivo

Permitir que o TriView Workspace mantenha áreas de trabalho salvas, restaure o último estado utilizado e preserve configurações durante atualizações.

## Implementação

- catálogo JSON com esquema versionado;
- `WorkspaceRepository` com gravação atômica;
- `WorkspaceSessionEngine` independente da GUI;
- restauração automática do último workspace;
- criação por cópia, renomeação e exclusão;
- edição de títulos, tipos e destinos dos painéis;
- seleção de layouts disponíveis;
- migração do bundle único legado;
- quarentena de arquivo corrompido;
- fallback seguro para o workspace padrão;
- armazenamento em `XDG_DATA_HOME`;
- CLI e diagnóstico atualizados;
- testes automatizados;
- documentação e ADR-0004.

## Critérios técnicos

- [x] esquema persistente com versão explícita;
- [x] criação e gravação local;
- [x] reabertura após reiniciar o processo;
- [x] restauração do último workspace utilizado;
- [x] edição, renomeação e exclusão;
- [x] seleção de layouts disponíveis;
- [x] recuperação de JSON corrompido;
- [x] dados separados do diretório versionado do atualizador;
- [x] diagnóstico preservado;
- [x] testes de persistência, migração e sessão;
- [x] versão atualizada para `0.3.0`;
- [x] documentação e ADR atualizadas;
- [ ] CI validada no HEAD final;
- [ ] fluxo visual validado no Linux Mint real.

## Teste de aceite esperado

1. atualizar o TriView Workspace;
2. criar um novo workspace pelo botão **Novo**;
3. renomear e editar ao menos um painel;
4. alternar para outro workspace;
5. fechar e abrir a aplicação;
6. confirmar restauração do último workspace;
7. excluir o workspace de teste;
8. confirmar que o último workspace restante não pode ser excluído.

## Limites

- cookies e processos de navegador não são restaurados automaticamente;
- novos layouts não são desenhados pela interface nesta versão;
- captura, gravação, Application Engine, plugins e Wayland nativo permanecem posteriores.
