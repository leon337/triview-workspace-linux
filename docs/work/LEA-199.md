# LEA-199 — PDF Engine incorporado

Status: implementação concluída; aguardando CI e teste no Linux Mint.

## Entregas

- validação de caminho e extensão `.pdf`;
- PDF Adapter e PDF Engine;
- detecção de Xreader, Evince, Atril, Okular, Zathura e MuPDF;
- incorporação X11 ou fallback externo;
- integração ao registro genérico de runtime;
- testes de arquivo, adaptador, ciclo de vida e fallback;
- versão candidata `0.6.0`;
- ADR-0007.

## Critérios

- [x] PDF válido é preparado para abertura;
- [x] arquivo ausente ou inválido é rejeitado;
- [x] ciclo de vida reutiliza Panel Runtime;
- [x] Browser, Application e Terminal preservados;
- [ ] CI final;
- [ ] visualizador validado no Linux Mint.

## Teste esperado

Instalar o candidato LEA-199, configurar um painel `pdf` com o caminho completo de um arquivo local e confirmar estado `ATIVO` ou `EXTERNO`.
