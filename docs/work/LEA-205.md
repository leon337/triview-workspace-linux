# LEA-205 — Workspace Hub com templates e importação

Status: implementação concluída; aguardando CI e teste sequencial no Linux Mint.

## Entregas

- biblioteca local versionada para workspaces e templates;
- categorias, favoritos e busca textual;
- importação e exportação em JSON;
- validação de esquema, tipo, tamanho e arquivo regular;
- rejeição de links simbólicos e sobrescrita silenciosa;
- prévia estrutural sem executar destinos dos painéis;
- criação de workspace independente a partir de item reutilizável;
- interface gráfica com salvar, importar, exportar, favoritar e usar;
- gravação atômica dos documentos e metadados;
- candidato isolado `0.12.0`;
- testes automatizados e ADR-0013.

## Critérios

- [x] workspace pode ser exportado e importado sem perda estrutural;
- [x] template gera workspace e layout com identidades independentes;
- [x] arquivo incompatível ou inseguro é rejeitado;
- [x] busca, favoritos e categorias funcionam;
- [x] prévia não inicia painéis;
- [x] colisões não sobrescrevem itens silenciosamente;
- [ ] CI final;
- [ ] fluxo gráfico validado no Linux Mint.

7. visualizar os painéis sem iniciá-los;
8. usar o template e confirmar a criação de workspace independente;
9. tentar importar arquivo incompatível e confirmar a rejeição.
