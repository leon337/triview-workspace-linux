# LEA-202 — Plugin Engine seguro

Status: implementação concluída; aguardando CI e teste no Linux Mint.

## Entregas

- manifesto JSON com esquema e API versionados;
- descoberta somente na raiz permitida;
- rejeição de symlinks, IDs inválidos e versões incompatíveis;
- ativação e desativação explícitas;
- arquivo de estado gravado atomicamente;
- Plugin Adapter para painéis `custom`;
- execução declarativa pelo Application Engine, sem shell;
- isolamento de falhas e diagnósticos;
- gerenciador simples na GUI;
- plugin de exemplo `text-editor` e instalador;
- versão candidata `0.9.0`;
- testes e ADR-0010.

## Critérios

- [x] plugin válido é descoberto, mas não ativado silenciosamente;
- [x] plugin incompatível é rejeitado com diagnóstico;
- [x] falha não derruba a aplicação;
- [x] nenhum módulo Python de terceiros é importado;
- [x] argumentos extras dependem do manifesto;
- [ ] CI final;
- [ ] plugin de exemplo validado no Linux Mint.

## Teste esperado

Instalar o candidato LEA-202, executar `scripts/install-example-plugin.sh`, criar um painel `custom` com destino `plugin:text-editor`, abrir o gerenciador **Plugins** e confirmar a execução controlada.
