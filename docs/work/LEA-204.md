# LEA-204 — Session Engine completo

Status: implementação concluída; aguardando CI e teste sequencial no Linux Mint.

## Entregas

- estado operacional com esquema versionado;
- gravação atômica e quarentena de arquivo inválido;
- detecção de encerramento limpo ou interrompido;
- registro de painéis abertos, incorporados ou externos;
- hash de configuração sem persistir destinos ou credenciais;
- invalidação automática quando a configuração do painel muda;
- sincronização periódica sem gravações redundantes;
- confirmação explícita antes de restaurar processos;
- restauração escalonada dos painéis aprovados;
- finalização limpa ao fechar a aplicação;
- módulo candidato `triview_workspace.gui_sessions`;
- instalador de candidato com módulo gráfico explícito;
- testes de privacidade, recuperação e corrupção;
- ADR-0012.

## Critérios

- [x] estado operacional possui versão explícita;
- [x] destinos, tokens, cookies e conteúdo de terminal não são armazenados;
- [x] configuração alterada invalida a restauração correspondente;
- [x] restauração exige confirmação do usuário;
- [x] encerramento limpo e interrupção são distinguíveis;
- [x] arquivo inválido é preservado antes do fallback;
- [x] candidato usa dados e estado isolados;
- [ ] CI final;
- [ ] restauração após fechamento normal validada no Linux Mint;
- [ ] recuperação após encerramento forçado validada no Linux Mint.

## Teste esperado

1. instalar e abrir o candidato;
2. abrir dois painéis executáveis;
3. fechar normalmente;
4. abrir novamente e aceitar a restauração;
5. alterar o destino de um painel e confirmar que ele deixa de ser elegível;
6. encerrar o processo à força durante uma sessão;
7. abrir novamente e verificar o aviso de interrupção;
8. rejeitar a restauração e confirmar que nenhum processo é iniciado.
