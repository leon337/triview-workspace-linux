# LEA-203 — Layout Engine avançado e editor visual

Status: implementação concluída; aguardando CI e teste no Linux Mint.

## Entregas

- validação central de limites e sobreposição;
- presets columns, stack, grid, focus-left e two-plus-one;
- breakpoints estreito, médio e largo;
- editor visual com coordenadas normalizadas e prévia;
- criação e persistência de layouts sem sobrescrita silenciosa;
- seleção imediata do novo layout;
- versão candidata `0.10.0`;
- testes e ADR-0011.

## Critérios

- [x] layouts fora da área são rejeitados;
- [x] slots sobrepostos são rejeitados;
- [x] presets cobrem um a quatro ou mais painéis;
- [x] breakpoints são derivados sem alterar o catálogo;
- [x] editor mostra prévia antes de salvar;
- [x] layout salvo sobrevive ao reinício;
- [ ] CI final;
- [ ] criação e responsividade validadas no Linux Mint.

## Teste esperado

Instalar o candidato LEA-203, clicar em **Novo layout**, aplicar presets, alterar coordenadas, visualizar a prévia, salvar e redimensionar a janela para confirmar as variantes responsivas.
