# LEA-198 — Terminal Engine incorporado

Status: implementação concluída; aguardando CI e teste no Linux Mint.

## Entregas

- `TerminalPanelAdapter`;
- `TerminalEngine` com uma sessão por painel;
- seleção de emulador instalado;
- shell configurável e validado;
- suporte inicial a xterm, XFCE Terminal, GNOME Terminal, Kitty, Alacritty e Konsole;
- incorporação X11 pelo Panel Runtime;
- fallback externo explícito;
- registro genérico de controladores para Browser, Application e Terminal;
- shell gráfico genérico;
- testes e ADR-0006;
- versão candidata `0.5.0`.

## Critérios

- [x] Terminal Adapter integrado;
- [x] shell validado sem shell intermediário;
- [x] emulador detectado por prioridade;
- [x] incorporação e fallback reutilizam Panel Runtime;
- [x] ciclo de vida testado;
- [x] Browser e Application Engines preservados;
- [ ] CI final;
- [ ] terminal incorporado no Linux Mint;
- [ ] fallback externo validado.

## Teste esperado

Instalar o candidato LEA-198, configurar um painel `terminal` com destino `bash`, abrir, redimensionar e reabrir. O painel deve ficar `ATIVO` quando incorporado ou `EXTERNO` quando o emulador não aceitar incorporação.
