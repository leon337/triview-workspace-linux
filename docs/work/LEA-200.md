# LEA-200 — Capture Engine por painel

Status: implementação concluída; aguardando CI e teste no Linux Mint.

## Entregas

- Capture Engine independente da GUI;
- backends X11 `maim` e ImageMagick `import`;
- captura pelo identificador da janela do painel;
- botão Print habilitado para qualquer tipo de painel;
- organização por workspace, painel e data;
- gravação por arquivo parcial e troca final;
- histórico `capture-history.jsonl`;
- processamento assíncrono e feedback visual;
- versão candidata `0.7.0`;
- testes e ADR-0008.

## Critérios

- [x] captura somente o painel selecionado;
- [x] diretório e nome são previsíveis;
- [x] histórico auditável é gerado;
- [x] falhas não encerram a aplicação;
- [x] funciona de forma independente do tipo do painel;
- [ ] CI final;
- [ ] captura validada no Linux Mint.

## Teste esperado

Instalar o candidato LEA-200, abrir qualquer painel e clicar em **Print**. Confirmar que o PNG contém somente o painel selecionado e foi salvo em `~/Pictures/TriView Workspace/Captures`.
