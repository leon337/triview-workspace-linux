# Visual v2 — contrato de área útil

## Decisão corrigida

O layout principal não é definido por larguras fixas em pixels.

- cada um dos três painéis ocupa exatamente um terço da largura útil;
- os painéis ocupam 96% da altura útil do workspace;
- a conversão para pixels existe somente na fronteira final exigida pelo Tkinter;
- a barra superior foi reduzida a uma única linha;
- a barra inferior global foi removida da apresentação principal;
- título, rodapé e espaçamentos internos dos cards foram reduzidos;
- o conteúdo incorporado é o elemento dominante da janela.

## Critério visual

A moldura da aplicação deve organizar o trabalho, não competir com ele. O usuário deve perceber primeiro ChatGPT, GitHub e Terminal; controles administrativos ficam compactos e secundários.
